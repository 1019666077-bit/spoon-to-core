# 帝国主轴拍板要点

源自 2026-09 拍板草案，已并入 `01_GDD.md` 与阶段 0′ 代码。不是竞品设计抄录。

## 主循环

手点土面 → 工具成长（碗 → 铲 → 魔改）→ 雇工自动化 → 大技能树（≥40 节点、≥4 分支）→ 层末「继续搜刮 / 下潜 / 回 Home」→ 破局技 → Stats。

Home = 商店 / 雇工 / 树 / Stats。地面基地建设降权不验收。

## 降权

- 邻格格挖迷宫
- 二维背包返程小游戏
- 地面基地建设模拟

旧路径可关、勿删到测试全红。主 UI 必须走点击土区。
