# 《一勺到底 / Spoon to the Core》

原创 2D 横屏**点击挖土帝国**。手点土面，碗升铲，雇工与大树把坑往地心推。

- 引擎：Cocos Creator 3.8.8 + TypeScript
- 首发平台：CrazyGames Web、Android
- 后续平台：微信小游戏
- 单局时长：3—5 分钟
- 变现方式：激励广告为主，轻内购为辅
- 工程版本：`0.7.0-empire1`（阶段 1′ 第一口帝国循环）

名、UI、雇工、树节点、掉落与文案必须原创，禁止抄 Dirt Clicker 专名。

---

## 源码位置（阶段 1′）

正式工程在 [`game/`](game/)。用 **Cocos Creator 3.8.8** 打开该目录，场景为 `assets/scenes/boot.scene`。

```text
game/
  assets/scripts/     domain / data / gameplay / ui / save / bootstrap
  assets/config/      工具碗→铲、雇工、≥40 节点树、五层土面皮肤
  assets/scenes/      boot.scene
  tests/              Node 单测，不依赖编辑器
```

不依赖 Creator 时，在 `game/` 下（Node 22+）：

```text
cd game
npm install
npm test
npm run typecheck
```

Grok Build 里的网页预览只是同一套 domain 的宿主，**不是**正式运行层。正式版本仍是这个 Cocos 工程。

阶段 1′ 已完成：点击/按住挖土掉泥金物、碗→灶间铲/工地铁铲、牙孢子伴掘虫 tick、大树可点（器脉/编制有感）、层末三态真下潜、过热铲破局、`schemaVersion: 4`。Creator 实机画面仍需本地编辑器打开 `boot.scene`。

## 硬性约束

1. 玩法规则与 Cocos 节点分离，`domain` / 纯函数 gameplay 可在 Node 单测
2. 方块、宝物、工具、地层、雇工、技能树、任务、广告奖励全部走配置
3. 每局使用 seed 随机数；旧地图生成可复现，但主 UI 走点击土区
4. 平台能力必须通过 `PlatformAdapter` 调用
5. 存档必须带 `schemaVersion` 和迁移函数
6. 灰盒阶段只用程序化色块与文字占位
7. CrazyGames Basic Launch 阶段完全隐藏广告入口
8. 名/UI/工人/树节点/掉落/文案原创，禁止 Dirt Clicker 专名
